# Справочник чатов

Список известных чатов. Источник может быть и получателем; сам факт получения сообщений не означает разрешения или обязательства ему рассылать. Перед подготовкой укажите получателя или подтвердите список рассылки. Папки входящих стабильны, даже если отображаемое имя чата меняется.

| Чат | Папка источника | Роль | Особые условия |
| --- | --- | --- | --- |
| Mercury Finance | `mercury-finance` | Источник; получатель не подтверждён | Не согласованы |
| OTCu1 new 27 / РР | `otcu1-new-27-rr` | Источник; получатель не подтверждён | Не согласованы |

Добавляйте другие чаты и клиентов по мере поступления данных. Для каждого можно указать, принимает ли он предложения, предпочтительный формат, правила цены и ограничения. Пользователь указывает отдельно, какие чаты являются источниками и какие — получателями; один чат может иметь обе роли. «+1%» означает увеличение ставки на 1 процентный пункт и применяется только к явно указанным позициям; выбор между источниками пока не согласован.
