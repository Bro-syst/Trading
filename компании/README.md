# Компании и документы

Папка каждой компании называется по ИНН: `компании/<ИНН>/`. В её `README.md` записываются название и ИНН, перечень документов с источником, датой получения и примечаниями, а также ссылки на ежедневные предложения. Сами документы сохраняются без изменения в подпапке `документы/` с понятными именами, датой получения и источником. Оригинальное имя и источник сохраняются в записи об исходном сообщении. Новые версии не перезаписывают старые: добавьте отдельный файл и отметьте, какая версия подтверждена актуальной, если это известно.

Документ связывается с компанией по ИНН; по возможности сверьте ИНН и название внутри документа с сообщением. Несовпадение или нечитаемый документ пометьте и запросите уточнение, не используйте его для передачи как подтверждённую карточку. Компания без ИНН помещается во временную папку только после присвоения уникального идентификатора; совпадения не предполагаются.

Карточка может содержать реквизиты, актуальность которых со временем меняется. Наличие файла не подтверждает их актуальность. При запросе на подготовку передачи укажите имеющуюся карточку и источник, дату и возможные ограничения; передавайте её вместе с условиями только по запросу пользователя. Если у компании несколько версий или источников с разными реквизитами, не выбирайте их молча: покажите различия и запросите решение. Подготовьте ссылку на конкретный файл, чтобы пользователь мог его прикрепить; физическая отправка и её подтверждение фиксируются в журнале передач.
